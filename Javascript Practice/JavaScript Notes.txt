*String Methods*
Allow you to manipulate and work with texts (strings)


JavaScript provides a variety of methods for working with strings. Here's a simplified overview of the most commonly used string methods:

### Basic String Methods

1. **`length`**: Returns the length of a string.
   ```javascript
   let str = "Hello";
   console.log(str.length); // 5
   ```

2. **`charAt(index)`**: Returns the character at the specified index.
   ```javascript
   console.log(str.charAt(1)); // 'e'
   ```

3. **`charCodeAt(index)`**: Returns the Unicode of the character at the specified index.
   ```javascript
   console.log(str.charCodeAt(1)); // 101
   ```

4. **`toUpperCase()`**: Converts the string to uppercase.
   ```javascript
   console.log(str.toUpperCase()); // 'HELLO'
   ```

5. **`toLowerCase()`**: Converts the string to lowercase.
   ```javascript
   console.log(str.toLowerCase()); // 'hello'
   ```

### Searching and Extracting

6. **`indexOf(substring)`**: Returns the index of the first occurrence of the specified substring. Returns -1 if not found.
   ```javascript
   console.log(str.indexOf('e')); // 1
   ```

7. **`lastIndexOf(substring)`**: Returns the index of the last occurrence of the specified substring. Returns -1 if not found.
   ```javascript
   console.log(str.lastIndexOf('l')); // 3
   ```

8. **`includes(substring)`**: Checks if the string contains the specified substring.
   ```javascript
   console.log(str.includes('ell')); // true
   ```

9. **`startsWith(substring)`**: Checks if the string starts with the specified substring.
   ```javascript
   console.log(str.startsWith('He')); // true
   ```

10. **`endsWith(substring)`**: Checks if the string ends with the specified substring.
    ```javascript
    console.log(str.endsWith('lo')); // true
    ```

### Substring Extraction

11. **`substring(start, end)`**: Extracts a substring between the start and end indexes (end not included).
    ```javascript
    console.log(str.substring(1, 4)); // 'ell'
    ```

12. **`slice(start, end)`**: Extracts a part of a string and returns it as a new string (end not included).
    ```javascript
    console.log(str.slice(1, 4)); // 'ell'
    ```

13. **`substr(start, length)`**: Extracts a substring from the start index, up to the specified length.
    ```javascript
    console.log(str.substr(1, 3)); // 'ell'
    ```

### Modifying Strings

14. **`replace(substring, newSubstring)`**: Replaces the first occurrence of a substring with a new substring.
    ```javascript
    console.log(str.replace('l', 'y')); // 'Heylo'
    ```

15. **`replaceAll(substring, newSubstring)`**: Replaces all occurrences of a substring with a new substring.
    ```javascript
    console.log(str.replaceAll('l', 'y')); // 'Heyyo'
    ```

16. **`trim()`**: Removes whitespace from both ends of a string.
    ```javascript
    let spacedStr = "  Hello  ";
    console.log(spacedStr.trim()); // 'Hello'
    ```

17. **`concat(string1, string2, ...)`**: Concatenates one or more strings.
    ```javascript
    let str2 = " World";
    console.log(str.concat(str2)); // 'Hello World'
    ```

### Splitting and Joining

18. **`split(separator)`**: Splits a string into an array of substrings using the specified separator.
    ```javascript
    let sentence = "Hello World";
    console.log(sentence.split(' ')); // ['Hello', 'World']
    ```

19. **`join(separator)`**: Joins an array of strings into a single string with the specified separator.
    ```javascript
    let words = ['Hello', 'World'];
    console.log(words.join(' ')); // 'Hello World'
    ```

### Template Literals

20. **Template Literals**: Use backticks (\``\`) for multi-line strings and embedded expressions.
    ```javascript
    let name = "John";
    let greeting = `Hello, ${name}!`;
    console.log(greeting); // 'Hello, John!'
    ```

These methods cover most of the basic operations you might need to perform on strings in JavaScript.

what will happen here is essentially: b = 1 && a = 2; instead of the a = 1 && b = 2

//Swap two elements in an array

const colors = ["red", "green", "blue", "black", "white"];

[colors[0], colors[4]] = [colors[4], colors[0]]

Same idea as the first example
what will happen here is essentially: ["white", "green", "blue", "black", "red"]

//Assign array elements to variables

const colors = ["red", "green", "blue", "black", "white"];
